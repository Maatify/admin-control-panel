# Admin Control Panel Agent Guidelines

This repository uses the pinned engineering-standards snapshot and the
Admin-specific adoption decisions recorded in
[`docs/standards/STANDARDS_SOURCE.md`](docs/standards/STANDARDS_SOURCE.md).

- Before planning, implementing, reviewing, or validating any task, start with
  [`docs/index.md`](docs/index.md). It defines the mandatory reading order,
  including the AI collaboration standard.
- Read [`docs/standards/ADMIN_ADOPTION_POLICY.md`](docs/standards/ADMIN_ADOPTION_POLICY.md)
  when a task touches standards, module boundaries, permissions, API
  contracts, or project bootstrapping.
- The documents under `docs/standards/` are the local standards reference.
  Do not create competing copies of their general rules.
- Project-specific rules belong here or in the authoritative project
  documentation; do not alter the upstream standards repository from this
  project.
- Upgrade the pinned snapshot through a separate, reviewable change after
  verifying the upstream commit and its impact on this repository.
